# SetuAI v2 API reference

Generated by `scripts/gen_v2_api_doc.py` from the running application's OpenAPI schema and from the role table that `tests/v2_api/test_api_roles.py` verifies against real requests. Do not edit by hand; `python3 scripts/gen_v2_api_doc.py` rewrites it and a test fails if it is stale.

All paths are under `/api/v2`. Authenticate with `Authorization: Bearer <JWT>`. Project authority comes from an ACTIVE membership of the project in the path.
Errors: `{"error": {"code", "message", "details"}}`. Lists: `{"items", "limit", "offset", "next_offset"}` (limit 1-200). Create endpoints accept an `Idempotency-Key` header (claims, corrections, issues).

Roles: **M** Project Manager · **S** Supervisor · **E** Site Engineer. The letters are who passes the permission gate; finer rules (own records only, no claim content for the PM) are enforced by the domain services and the database and described in the summary.
